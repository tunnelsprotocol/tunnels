# Instructions for AI assistants

Before writing or changing ANY code in this repository, read, in order:
1. docs/llms.txt                — hard constraints and surprising behaviors
2. docs/implementation-rules.md — 15 binding rules
3. docs/deliberately-absent.md  — features that are missing ON PURPOSE. Do not add them.

Tunnels is small, deliberate, and permanent. If a task appears to require
violating a rule or filling an "absence," the task is wrong — stop and say so.
Applications integrate per docs/building-an-application.md.
